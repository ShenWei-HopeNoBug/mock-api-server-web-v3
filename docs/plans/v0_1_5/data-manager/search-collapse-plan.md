# outputManager 搜索区折叠方案

> 状态：已实施
> 范围：本仓 `apps/dataManager/views/outputManager/index.vue`

## 1. 背景

dataManager 主界面 header 卡内 SearchForm 有 9 个搜索字段，占高过大（form-wrapper max-height 168px + 工具行），挤压表格可视区。

## 2. 目标

搜索区可展开/收起，**v-show 实现**（组件不卸载，表单值/校验/滚动态保留）；折叠态 header 只剩一行：`筛选` toggle + `新增 Mock 接口`；展开态为 **absolute 悬浮层**盖在表格上方，不占用布局高度（popover 语义）。

## 3. 改动清单

| #   | 位置   | 改动                                                                                                                                           | 说明                                                                                              |
| --- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 1   | 模板   | header 重构为 `collapse-row`（筛选 toggle + 新增按钮，space-between）+ `v-show` 折叠区（search-bar + tool-bar）                                | `批量删除` 随折叠区收起——其作用域本就是当前筛选条件，随 search-bar 一体收放语义一致且防误触       |
| 2   | script | `searchCollapsed = ref(true)` 默认折叠；`activeFilterCount` computed 数提交态非空字段，>0 时按钮文案 `筛选 (n)`；`onSearchSubmit` 末尾收起浮层 | 默认折叠由占高诉求驱动；生效数徽标保筛选发现性；提交即收起看结果为最自然收合时机                  |
| 3   | style  | `.header` `position: relative` 作锚点；`.search-area` `absolute; top:100%` 浮层（panel 底/soft 边/8px 圆角/阴影/内边距，`z-index:10` 压表格）  | antd card 根不裁切已验证（overflow:hidden 仅在 Meta detail 与 loading 态）；v-show 瞬时切换无动画 |

## 4. 不改动的部分

- `SearchForm`/`useSearchFormResize`/表格/接口层：零改动
- 搜索/批量删/分页逻辑：零改动

## 5. 影响面

| 项       | 评估                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------ |
| 文件     | 1 代码文件                                                                                                               |
| 行为变化 | 默认折叠为交互变更（旧版首屏即见 9 字段）；toggle + 生效数徽标保发现性；展开为悬浮层不占高、盖表格上部；提交搜索自动收起 |
| 高度收益 | header 恒定单行高（~50px），较现状省 ~200px，展开态也不挤压表格                                                          |
| 风险     | 低，纯展示层                                                                                                             |

## 6. 验收

- `lint:check`/`format:check`/`build` 过
- dev 目检：默认只剩筛选+新增一行 → 点筛选展开悬浮层盖表格上部（header 高度不变）→ 提交筛选自动收起，按钮显示 `筛选 (n)` → 表格高度随 header 收缩自动回填（`v-dom-resize` 既有机制）
